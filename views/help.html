뉴스가 도착하지 않으셨나요?

구독은 정상적으로 등록되어 있지만, 카카오톡 채널 친구 추가가 되어 있지 않으면 매일 아침 뉴스를 받으실 수 없어요. 아래에서 1분 만에 해결됩니다.

!
친구톡은 '카카오톡 채널 친구'에게만 전송됩니다.
카카오톡 정책상, 채널 친구가 아닌 분께는 발송할 수 없어요.

1분 만에 해결하기

1
아래 노란 버튼을 눌러 채널 친구 추가
카카오톡이 열리며 '친구 추가' 버튼이 표시됩니다.
2
'채널 추가' 버튼 탭
추가하신 번호와 구독 번호가 동일한지 꼭 확인해주세요.
3
내일 오전 8시부터 자동 수신
별도 설정 없이 매일 아침 뉴스가 도착합니다.
K 카카오톡 채널 친구 추가

이미 친구 상태라면 이 단계는 건너뛰셔도 됩니다.

⚙️
친구 추가도 했는데 안 오시나요?
카카오톡의 광고/마케팅 메시지 수신이 꺼져 있을 수 있어요.

매일 발송되는 뉴스 친구톡은 카카오 정책상 광고성 메시지로 분류됩니다. 카카오톡에서 마케팅 메시지를 차단해두셨다면 받을 수 없어요. 아래 두 방법 중 하나로 켜주세요.

A
브리픽 채널만 따로 켜기 권장
  • 카카오톡 친구·채팅 탭에서 브리픽 채널 진입
  • 채널 상단 점 3개(⋯) 또는 톱니 아이콘 탭
  • "광고/마케팅 메시지 수신" 항목 켜기
B
카카오톡 전체 설정으로 켜기
  • 카카오톡 더보기(⋯) → 설정(톱니)
  • 개인/보안 → 광고성 정보 수신
  • 카카오톡 채팅 수신 동의
