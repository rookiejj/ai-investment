오늘 날짜 기준으로 6개 탭 전체 최신 정보를 조사하고 데이터 파일을 갱신해 커밋·푸시까지 완료해. 질문 없이 끝까지 진행 — 모든 판단은 에이전트가 내린다.

**대상 탭**: 미국 주식(stocks) · 한국 주식(kr) · AI 기업(ai) · 유니콘(unicorn) · 원자재·크립토(commodity).
일본 주식(jp)은 UI에서 제외됐으므로 이 커맨드에서 조사하지 않음. 필요 시 `/update-jp` 별도 호출.

**파이프라인 (사용자 확인 없이 끝까지)**:

1. **조사** — 6개 탭을 병렬 에이전트로 웹검색. CLAUDE.md의 "변경 감지 방법론"과 각 탭 업데이트 체크리스트를 준수.
   - 대표 상위 종목/기업 개별 검색 + 섹터·테마 광역 스캔 병행 (폐쇄 루프 방지)
   - 각 탭의 rs에 명시된 이벤트가 여전히 최신 상태인지 검증
   - 외부 서프라이즈(IPO·대형 M&A·신규 카테고리 리더)도 포착

2. **판단** — 조사 결과를 각 `data/*-data.js`와 비교해 편집 기준에 부합하는 항목만 보수적으로 선정.
   - 제외 규칙(회계이슈·재무악화·상장/인수 등) 적용 시 즉시 교체
   - 새 종목 추가 체크리스트(3개 이상 Yes) 충족 시에만 스왑
   - 애매하면 건드리지 않는다 (보수적 편집 원칙)

3. **편집** — 변경 필요한 `data/*-data.js` 파일 수정 (최소 diff, 카테고리당 정확히 7개 유지 — 유니콘 7, 원자재·크립토 4).
   - **관점 (전 탭 공통)**: CLAUDE.md [🆕 기관급 톤 가이드] 적용 — 매크로·밸류에이션·cross-asset·정책 4가지 렌즈 중 사건 본질에 가장 맞는 *하나*의 렌즈를 자연어로 결합. 모든 줄·모든 항목에 강제 X — 사건에 맞는 곳에만. 12단어 rs 한도·summary 첫 줄 헤드라인 우선 룰·탭 콘텐츠 독립성 원칙 그대로 유효.
   - **🔴 시세는 `data/prices-snapshot.json`에서 (엄수)**: summary·rs·detail에 KR/US **개별 종목 가격·등락률**을 쓸 땐 이 파일(`prices[티커]={c,pc,chg}`)을 1차 소스로 — 기억·추정·창작 금지. 프리마켓(07시 실행)엔 장중 등락률을 만들지 말고 직전 종가(`c`) 사용. 날짜에 "마감/반등"을 붙일 땐 `TZ=Asia/Seoul date`로 거래일 확인(토·일·휴장일 금지). 파일에 없는 지수 레벨만 웹검색 보충하되 방향은 스냅샷과 일치. 상세는 CLAUDE.md [현재가·등락률은 라이브 피드와 대조].
   - **🔴 summary 가독성 (엄수)**: 각 summary 줄은 `[주체 + 핵심 숫자] - [쉬운 풀이말]` 구조, **줄당 숫자 ≤2개**. 곁다리 밸류·매크로 수치(forward P/E·10y gap·bp·컨센 대비 % 여러 개)는 detail·rs에만 두고 summary에선 정성 표현으로 푼다. 금액은 한글 단위+통화(`1,165억달러`·`15조원`, 영어 B·T·M 금지). 상세는 CLAUDE.md [summary 작성 규칙]. 친구톡·신문 1면·인스타 전부 이 summary를 그대로 씀.

4. **이력** — 변경된 탭의 `data/*-update.js` 맨 앞에 새 엔트리 prepend.
   - date: 현재 KST 시간 (`TZ=Asia/Seoul date +"%Y-%m-%d %H:%M KST"`)
   - 동일 날짜 엔트리 덮어쓰기 금지 (누적 원칙)
   - 사용자향 자연어 문체 (내부 필드명·편집 메타 금지: "rs 갱신", "~반영" 등)
   - 제외·추가 사유는 `detail`에 자연어로 명시

5. **🔴 첫 줄 대조 (엄수 — 병렬 작성이라 이 단계 없으면 1면 도배 못 잡음)** — 커밋 전, 갱신한 각 탭 `*-update.js` 최신 엔트리의 **summary 첫 줄 5개(kr·stocks·ai·commodity·unicorn)를 한자리에 나열**하고 CLAUDE.md [첫 줄 충돌 금지 - 커밋 직전 첫 줄 대조 자기검증] 대로 점검:
   - 두 탭 이상 첫 줄이 같은 고유명사(기업·자산·인물·사건명) 2개 이상 공유 → 동일 사건. 소유 도메인 탭 1개만 남기고 나머지는 자기 도메인 **다른 주체** 사건으로 교체. 꼬리말만 자기 탭용으로 바꾸는 건 해소 아님.
   - kr 첫 줄에 한국 외 종목·기업명 등장 → 한국 주체 사건으로 교체.
   - 위반 발견 시 해당 탭 첫 줄 재작성 후 다시 나열해 대조. 통과해야 다음 단계.

6. **버전** — `data/version.js`의 `DATA_VERSION` 값을 `TZ=Asia/Seoul date +"%Y%m%d-%H%M"` 출력으로 갱신.

7. **커밋·푸시** — 변경된 파일 스테이징 후 커밋·푸시:
   - 커밋 메시지: `데이터 자동 갱신 YYYY-MM-DD` (KST 날짜)
   - `git add data/` + `git commit` + `git push origin main`
   - pre-commit hook 실패 시 원인 파악 후 재시도 (skip 금지)

**조사 결과 변경할 항목이 없으면**: 커밋하지 말고 "변경 없음"만 간결히 보고하고 종료.

**보고 포맷**: 마지막에 변경 사항을 3~6줄로 요약 (탭별 주요 변경 + 커밋 해시). 상세 후보 테이블은 생략.
