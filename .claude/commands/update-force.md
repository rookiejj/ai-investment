⚠️ **수동 전용 / 테스트·정합성 점검용 명령 — 자동 트리거 금지**

`/update`의 변형. **정상 운영(`/update`·자동 트리거)에는 어떤 영향도 주지 않음.** 사용자가 슬래시 명령으로 직접 호출했을 때만 발동.

## 인자
- `$ARGUMENTS` — 시간 윈도우 (시간 단위, 정수). 예: `6` = 최근 6시간, `24` = 최근 24시간. 인자 없으면 기본 `6`.

## 핵심 의미 (반드시 이해할 것)

**/update-force {N}h는 "N시간 전 시점부터 새로 수집"하는 fresh 재수집 모드다.**

- N시간 윈도우의 뉴스를 **처음 보는 것처럼** 광역 재수집한다.
- 기존 엔트리에 같은 사건이 이미 있는지를 비교 기준으로 삼지 않는다 — 윈도우 안 사건은 모두 "수집 대상"으로 간주.
- 수집된 사건들로 **오늘(KST) 엔트리를 통합 재작성**한다.
- 따라서 **"신규 이벤트 0건" 결과는 이 모드의 의도와 모순**이며, 항상 1건 이상의 신규/보강 이벤트가 잡힌다(N시간 동안 시장에 사건 0건은 사실상 불가능).
- 결과: **항상 커밋이 생성된다.** force 마커가 git log에 한 줄 박혀야 정상 동작 검증.

> 이 의미는 정상 `/update`에 적용되지 않는다. 정상 운영은 CLAUDE.md "변경 감지 방법론" 그대로 — 매 실행 전 기간 재스캔 금지·조사는 보수적·"애매하면 건드리지 않는다" 유지.

## 차이점 (정상 `/update` 대비)

1. **시간 윈도우 강제 확장 + fresh 재수집**
   - 정상: 최근 1~2일 + 진행 중 이벤트 한정, 기존 엔트리에 이미 반영된 사건은 재스캔 안 함.
   - 강제: 사용자 지정 N시간 윈도우 전체를 **처음부터 재수집**. 기존 엔트리 커버리지를 비교 기준으로 삼지 않음.

2. **"변경 없음 → 종료" 가드 해제 (영구 해제, 가드 자체 없음)**
   - 정상: 신규 이벤트 없으면 커밋 없이 "변경 없음" 보고 후 종료.
   - 강제: 가드 없음. fresh 재수집 의미상 신규는 항상 1건 이상 → 항상 통합 재작성·항상 커밋.
   - 정책 위반 점검(아래 항목)은 **부가** 작업: 위반 있으면 함께 정리.
     - **탭 콘텐츠 독립성 위반**: 한국 탭에 미국 기업명 직접 인용, AI 탭에 일반 빅테크 IR, 원자재 탭에 종목명 등
     - **트레이더 은어 잔존**: "비트", "미스", "인라인" → "컨센 상회/하회/부합"
     - **편집자 메타 표현**: "rs 갱신", "~반영", "맥락 갱신" 등 내부 필드명 노출
     - **친구톡 가독성**: summary 줄별 독립 사건 구조 위반(병렬 나열을 줄바꿈으로 분리한 경우 등)

3. **작용 범위 = 오늘(KST) 엔트리만**
   - 어제 이전 엔트리는 절대 소급 수정 금지 (CLAUDE.md 누적 원칙 그대로)
   - 통합 재작성도 동일 날짜 엔트리끼리만

4. **커밋 메시지 차별화**
   - 정상: `데이터 자동 갱신 YYYY-MM-DD`
   - 강제: `데이터 정합성 강제 갱신 YYYY-MM-DD (force, ${N}h)` — git log에서 한눈에 구분

## 파이프라인

1. **fresh 재수집** — N시간 윈도우로 5개 탭(미국·한국·AI·원자재·유니콘) 병렬 웹검색. 섹터별·티커별·주제별 다중 쿼리로 광역 스캔. 일본 탭 제외. **기존 엔트리 비교 단계 없음** — 윈도우 안 사건은 모두 수집 대상.
2. **정책 점검(부가)** — 오늘 엔트리의 `summary`·`detail`·`text` 전수 스캔, 위반 항목 표시.
3. **통합 재작성** — 1단계에서 수집된 사건들 + 2단계 위반 정정을 한꺼번에 오늘 엔트리에 통합. 기존 오늘 엔트리는 흡수·재구성. 어제 이전 엔트리는 손대지 않음.
4. **이력**: 통합 재작성 시 `date`는 현재 KST, `changes[].time`은 원래 이벤트 시각 보존.
5. **버전**: `data/version.js` 갱신.
6. **커밋·푸시**: force 차별화 메시지로 항상 커밋.

## 보고 포맷

3~6줄 요약. 다음 항목 명시:
- 시간 윈도우 (몇 시간 강제 적용했는지)
- fresh 수집 이벤트 건수 / 정책 위반 수정 건수
- 변경된 탭 목록
- 커밋 해시

## 주의

- 자동화(GitHub Actions·cron·다른 슬래시 명령)에서 호출 금지. 사람이 직접 입력해야만 발동.
- **정상 `/update`·자동 트리거에 이 force 의미가 새어들면 안 됨** — 정상 운영은 CLAUDE.md 보수적 조사 원칙 유지.
- 호출 직후 `git log -1` 보고 `(force,` 마커가 있는지 확인하면 정상 동작 검증 가능.
