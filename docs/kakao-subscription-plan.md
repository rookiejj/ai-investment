# 카카오톡 구독 마켓 펄스 서비스 기획서

## 1. 개요

AI 투자 마켓 펄스 대시보드(7개 탭: 미국·한국·일본 주식, AI 기업, 글로벌 ETF, 원자재·매크로, 유니콘)의 핵심 정보를 **카카오톡으로 매일 발송**하는 유료 구독 서비스.

### 서비스 모델
- **월 정액제** 구독
- 매일 1회 마켓 펄스 메시지 발송
- 카카오페이 자동 결제 (월 갱신)

## 3. 핵심 구성 요소

### 3-1. 데이터 자동 갱신

| 항목 | 내용 |
|------|------|
| 도구 | Claude Code `/schedule` (원격 실행) |
| 주기 | 매일 KST 08:00 |
| 대상 | 7개 탭 전체 (`/update` 스킬) |
| 결과 | GitHub 자동 커밋/PR |
| 특이사항 | 창 닫아도 동작 (Anthropic 서버 실행) |

### 3-2. 카카오톡 메시지 발송

| 항목 | 내용 |
|------|------|
| 채널 | 카카오톡 비즈니스 채널 |
| 발송 방식 | **알림톡** (템플릿 기반, 건당 8~15원) |
| 대안 | **친구톡** (이미지 포함 가능, 건당 15~25원) |
| 대행사 | 솔라피(SOLAPI), 알리고, 비즈톡 중 택1 |

**알림톡 vs 친구톡 비교:**
- 알림톡: 정보성 메시지, 템플릿 승인 필요, 저렴
- 친구톡: 광고성 가능, 이미지 첨부 가능, 비쌈

### 3-3. 결제 시스템

| 항목 | 내용 |
|------|------|
| PG | 카카오페이 정기결제 |
| 방식 | 빌링키 발급 → 매월 자동 청구 |
| 테스트 | 샌드박스 환경 제공 (TC0ONETIME) |
| API | `open-api.kakaopay.com/online/v1/payment/*` |
| 대안 PG | 토스페이먼츠, NHN KCP (다중 결제수단 필요 시) |

## 4. 고객 경험 플로우

```
1. 고객이 카카오톡에서 채널 검색 → "친구 추가"
2. 채널 홈에서 "구독 신청" 버튼 탭
3. 카카오페이 정기결제 화면 → 결제 완료 (빌링키 발급)
4. "구독 완료" 알림톡 수신
5. 매일 오전: 투자 마켓 펄스 알림톡 수신
   ┌──────────────────────────────┐
   │ 📊 오늘의 투자 마켓 펄스         │
   │                              │
   │ ▸ 미국: NVDA +3.2%, ...      │
   │ ▸ 한국: 삼성전자 +1.5%, ...   │
   │ ▸ 원자재: 금 $2,450, ...     │
   │                              │
   │ [전체 보기] [구독 관리]        │
   └──────────────────────────────┘
6. 만료 3일 전: "구독 갱신 안내" 알림톡
7. 카카오페이 자동 결제 → "결제 완료" 알림톡
8. (결제 실패 시) "결제 수단 확인 요청" → 3일 후 재시도 → 실패 시 일시정지
```

## 5. 백엔드 서버 구조

```
kakao-briefing-server/
├── src/
│   ├── auth/                # 카카오 채널 연동
│   │   └── kakao.js         # OAuth, 채널 친구 관리
│   ├── payment/             # 정기결제
│   │   ├── billing.js       # 빌링키 발급/결제/취소
│   │   └── webhook.js       # 결제 결과 콜백
│   ├── subscription/        # 구독 관리
│   │   ├── model.js         # 구독 상태 (active/paused/expired)
│   │   └── service.js       # 구독 생성/갱신/해지 로직
│   ├── messaging/           # 메시지 발송
│   │   ├── alimtalk.js      # 알림톡 API (솔라피/알리고)
│   │   └── templates.js     # 메시지 템플릿 관리
│   ├── briefing/            # 마켓 펄스 생성
│   │   └── generator.js     # data/*.js → 메시지 포맷 변환
│   └── scheduler/           # 스케줄러
│       ├── daily-send.js    # 매일 마켓 펄스 발송 cron
│       ├── monthly-bill.js  # 매월 정기결제 cron
│       └── expiry-alert.js  # 만료 안내 cron
├── db/
│   └── schema.sql           # 구독자, 결제이력, 발송로그
├── .env                     # API 키 (카카오페이, 알림톡)
└── package.json
```

### DB 스키마 (핵심 테이블)

```sql
-- 구독자
CREATE TABLE subscribers (
  id            SERIAL PRIMARY KEY,
  kakao_id      VARCHAR UNIQUE NOT NULL,   -- 카카오 유저 ID
  status        VARCHAR DEFAULT 'active',  -- active / paused / expired
  subscribed_at TIMESTAMP,
  expires_at    TIMESTAMP
);

-- 결제 이력
CREATE TABLE payments (
  id            SERIAL PRIMARY KEY,
  subscriber_id INT REFERENCES subscribers(id),
  billing_key   VARCHAR,                   -- 카카오페이 빌링키
  amount        INT,
  status        VARCHAR,                   -- success / fail / refunded
  paid_at       TIMESTAMP
);

-- 발송 로그
CREATE TABLE send_logs (
  id            SERIAL PRIMARY KEY,
  subscriber_id INT REFERENCES subscribers(id),
  sent_at       TIMESTAMP,
  status        VARCHAR                    -- success / fail
);
```

## 8. 구현 로드맵

### Step 1 — 데이터 자동 갱신 (즉시 가능)
- Claude Code `/schedule`로 매일 데이터 업데이트 자동화
- GitHub에 자동 반영 확인

### Step 2 — 카카오톡 채널 + 알림톡 (1~2주)
- 카카오톡 비즈니스 채널 개설
- 알림톡 대행사 계약 및 템플릿 등록
- 마켓 펄스 메시지 포맷 설계 및 테스트 발송

### Step 3 — 결제 시스템 (1~2주)
- 카카오페이 가맹점 등록
- 빌링키 발급 → 정기결제 API 연동
- 샌드박스 테스트

### Step 4 — 백엔드 서버 통합 (2~3주)
- 구독 관리 + 결제 + 발송 통합 서버 개발
- DB 세팅 및 스케줄러 구현
- 만료 안내 / 결제 실패 처리 로직

### Step 5 — 테스트 및 런칭
- 전체 플로우 E2E 테스트
- 운영 환경 전환
- 소규모 베타 테스트 후 오픈
