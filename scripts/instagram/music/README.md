# Reels 배경음악

이 디렉토리에 mp3/m4a/wav/ogg 파일 1개를 두면 `render-reels.js`가 자동으로 합성합니다. 파일이 없으면 무음으로 출력됩니다.

## 트랙 선택 (royalty-free)

상업 사용·표기 불필요한 무료 라이브러리:

- **Mixkit**: https://mixkit.co/free-stock-music/tag/documentary/ — 다큐멘터리 톤 (Mixkit License: 자유 사용, 표기 불필요)
- **Pixabay Music**: https://pixabay.com/music/search/ambient%20documentary/ — Pixabay Content License (자유 사용)
- **YouTube Audio Library**: 채널 → 콘텐츠 → 라이브러리에서 무료 다운로드

## 톤 가이드

브리픽 톤(차분한 사실 정보 전달)에 맞는 트랙 특성:
- 차분한 ambient·cinematic·documentary
- 강한 드럼·보컬·가속 비트 피하기
- 30초 이상 길이 (실제 영상은 ~26초이지만 여유 둠)
- 시작·끝이 갑작스럽지 않은 페이드 톤

## 파일 명세

- 파일명: 자유 (예: `ambient-news.mp3`)
- 형식: mp3/m4a/wav/ogg
- 길이: 30초 이상 권장
- 비트레이트: 128kbps 이상
- 한 디렉토리에 여러 파일 두면 첫 번째(알파벳순)가 선택됨

## 라이선스 보존

다운로드한 트랙의 라이선스 텍스트(또는 출처 URL)를 이 README에 추가해 둘 것:

```
- track.mp3: [트랙 이름] by [작곡자] (Mixkit License) — https://mixkit.co/...
```
